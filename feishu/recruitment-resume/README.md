# 飞书招聘｜完整简历图片与 PDF 下载

当飞书招聘管理员禁止直接下载 PDF 简历时，本脚本用于导出当前账号已经有权查看的完整简历图片或 PDF。脚本支持多页简历、长图拼接、逐页图片、图片型 PDF，并会根据当前申请自动生成“职位-候选人”格式的文件名。请仅用于你有权访问和保存的简历。

## 安装

### 方式一：从 Greasy Fork 安装（推荐）

安装 Tampermonkey、Violentmonkey 等用户脚本管理器后，打开下面的脚本页面，点击“安装此脚本”即可：

[飞书招聘｜完整简历图片与 PDF 下载](https://greasyfork.org/zh-CN/scripts/596983-%E9%A3%9E%E4%B9%A6%E6%8B%9B%E8%81%98-%E5%AE%8C%E6%95%B4%E7%AE%80%E5%8E%86%E5%9B%BE%E7%89%87%E4%B8%8E-pdf-%E4%B8%8B%E8%BD%BD)

### 方式二：从 GitHub Raw 安装

1. 先安装 Tampermonkey 或 Violentmonkey。
2. 打开脚本源文件：

   [feishu-resume-downloader.user.js](https://raw.githubusercontent.com/i-square/userscripts-hub/main/feishu/recruitment-resume/feishu-resume-downloader.user.js)

3. 用户脚本管理器通常会自动打开安装页面，确认安装即可。

如果浏览器只是显示源代码，请复制页面内容，在用户脚本管理器中新建脚本后粘贴并保存。

## 功能

- **下载原始 PDF**：PDF 按原文件保存，不把截图伪装成 PDF。
- **下载完整图片**：按简历页序获取整页图片，不截取当前屏幕可见区域。
- **长图或逐页图片**：多页简历可以拼接成长图，也可以按页分别保存。
- **图片型 PDF**：图片附件或无法直接取得原 PDF 时，可生成图片型 PDF；该 PDF 不包含可搜索文字层。
- **自动命名**：优先使用当前申请的职位标题和候选人姓名，格式为 `职位-姓名`。
- **当前附件保护**：只处理当前选中的简历附件，切换候选人或附件时会停止本次导出，避免混入其他简历。
- **下载设置**：可以选择下载图片、PDF 或两者，并调整图片格式、清晰度和多页处理方式。

## 使用方法

1. 打开飞书招聘中的候选人详情页，并进入附件简历预览。
2. 等待简历预览完成，确认当前选中的是要导出的附件。
3. 在原“全屏”按钮左侧点击 **下载**。
4. 脚本会打开处理面板，显示当前导出进度；生成文件后会自动发起下载。
5. 如果浏览器阻止了连续下载，可以在处理结果面板中逐个点击文件名保存。

通常不需要先点击飞书原生的“全屏”按钮，也不需要把简历滚动到页面底部。

## 界面说明

| 控件 | 作用 |
| --- | --- |
| 下载 | 导出当前选中的完整简历图片和/或 PDF |
| 齿轮图标 | 打开下载格式、图片格式、清晰度和多页处理设置 |
| 处理面板 | 显示读取附件、生成图片和发起下载的进度 |
| 结果文件名 | 生成后可再次点击，单独保存某个文件 |

按钮组默认半透明，鼠标移入或键盘聚焦后会完整显示，以减少对飞书原页面工具栏的遮挡。

## 设置

| 设置项 | 可选内容 |
| --- | --- |
| 下载内容 | 图片、PDF、图片和 PDF |
| 图片格式 | PNG、JPG |
| 多页图片 | 拼接成长图、每页一张图片 |
| 超长处理 | 自动分成多张长图，或等比例缩小为一张长图 |
| 来源清晰度 | 优先使用 x3、x2 或 x1 图片档位，缺少时自动降级 |

设置会保存在用户脚本管理器的脚本存储中，不会保存候选人简历文件或临时下载地址。

## 文件名

文件名格式为：

```tex
职位-候选人.png
职位-候选人.pdf
```

如果职位和姓名接口暂时不可用，脚本会回退读取页面中的职位和候选人文本，并清理文件名中的非法字符。

多页模式和自动分卷模式会在文件名末尾追加页码或分卷序号。

## 常见问题

### 页面上没有“下载”按钮

- 确认脚本管理器已启用该脚本，并允许脚本在飞书页面运行。
- 确认当前页面是飞书招聘候选人详情页，地址通常包含 `/hire/`。
- 等待简历附件预览完成后刷新页面。
- 检查是否同时安装并启用了旧版本脚本，多个版本可能互相干扰。

### 点击后提示无法读取当前附件

请先在页面中打开一个具体的简历附件，等待预览完成，再点击“下载”。脚本只导出当前选中的附件，不会从页面中猜测其他文件。

### 浏览器没有自动保存全部文件

浏览器可能拦截同一页面连续下载多个文件。允许当前站点的连续下载，或在处理结果面板中逐个点击文件名保存。

### 图片清晰度不符合预期

可以在齿轮设置中提高来源清晰度。最终分辨率由飞书提供的附件预览资源决定，x3 不代表对原图进行数码放大。

## 适用页面

- `https://*.feishu.cn/hire/*`
- `http://*.feishu.cn/hire/*`

脚本只处理当前飞书招聘页面及其同源附件请求，不支持飞书客户端内嵌页面或无法提供当前附件信息的页面。

## 权限说明

脚本使用的用户脚本权限用于：

- 读取和保存下载设置；
- 在页面中添加下载按钮和设置面板；
- 发起当前飞书域名下的附件请求；
- 生成图片、PDF 和下载文件。

脚本不会上传简历、批量枚举候选人，也不会把简历内容发送到第三方服务。请仅导出你有权访问和保存的候选人简历，并遵守所在组织的数据管理要求。
