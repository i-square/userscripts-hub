# 飞书 PDF 缩略图嗅探 + 一键下载

针对飞书/Lark 知识库中"禁止下载"的 PDF 文档，自动捕获页面渲染的 WebP 缩略图，并支持一键批量下载。

**安装：** [点击安装（Greasy Fork）](https://greasyfork.org/zh-CN/scripts/578274-%E9%A3%9E%E4%B9%A6pdf%E7%BC%A9%E7%95%A5%E5%9B%BE%E5%97%85%E6%8E%A2-%E4%B8%80%E9%94%AE%E4%B8%8B%E8%BD%BD) | [直接安装（GitHub Raw）](https://raw.githubusercontent.com/i-square/userscripts-hub/main/feishu/pdf-thumbnail/feishu-pdf-webp-sniffer.user.js)

---

## 功能

- **自动嗅探**：通过 MutationObserver 监听 DOM 变动，实时捕获 `data:image/webp;base64,...` 格式的页面缩略图
- **虚拟滚动支持**：即使页面采用虚拟列表（已离屏的节点被卸载），仍能保留已捕获的图片数据
- **按页码命名**：文件名使用 `data-number` 属性（即 PDF 页码），输出如 `1.webp`、`2.webp`
- **过滤小图**：自动跳过低于阈值（默认 1 KB）的无效占位图
- **双下载兜底**：优先调用 `GM_download`，失败时自动回退到 Blob URL + `<a download>`
- **可配置**：内置设置面板，支持调整过滤阈值、下载间隔、是否仅抓 WebP 等参数，设置持久化保存

## 使用方法

1. 在飞书/Lark 知识库打开含 PDF 预览的页面
2. 工具栏出现禁用的"下载"按钮旁会自动注入 🔍 图标，点击展开控制面板
3. **下拉滚动**页面，让 PDF 缩略图逐页渲染，面板中"已捕获"数字会实时增长
4. 滚动到目标范围后，点击 **一键下载** 批量保存所有已捕获页图

## 界面说明

| 按钮     | 功能                                         |
| -------- | -------------------------------------------- |
| 一键下载 | 按页码顺序批量下载所有已捕获页图             |
| 停止     | 中断正在进行的下载任务                       |
| 重新扫描 | 手动触发一次 DOM 扫描                        |
| 查看列表 | 弹窗展示当前捕获清单（页码、大小、数据摘要） |
| 复制清单 | 将清单文本复制到剪贴板                       |
| 导出 TXT | 将清单导出为 `.txt` 文件                     |
| 清空     | 清除所有已捕获数据，重新开始                 |
| ⚙️ 设置   | 调整过滤阈值、下载间隔等参数                 |

## 设置项

| 设置             | 默认值  | 说明                                   |
| ---------------- | ------- | -------------------------------------- |
| 仅抓 WebP        | `true`  | 只收集 `image/webp` 格式的图片         |
| 过滤阈值（字节） | `1024`  | 小于此字节数的图片视为占位图，不予收集 |
| 下载间隔（ms）   | `180`   | 批量下载时每张之间的延迟，防止触发限速 |
| 扫描防抖（ms）   | `200`   | DOM 变动后的扫描延迟                   |
| 另存为弹窗       | `false` | 下载时是否弹出系统"另存为"对话框       |
| 调试日志         | `false` | 在控制台输出详细日志                   |

## 适用范围

- `https://*.feishu.cn/wiki/*`
- `https://*.larksuite.com/wiki/*`

## 依赖权限

- `GM_download` — 下载文件
- `GM_setClipboard` — 复制到剪贴板
- `GM_addStyle` — 注入样式
- `GM_getValue` / `GM_setValue` — 持久化配置

## 注意事项

- 脚本只捕获已渲染到页面的缩略图，**未滚动到的页面不会被收集**，请确保目标页面均已滚过
- WebP 缩略图分辨率由飞书服务端决定，通常非原始 PDF 清晰度
- 本脚本仅供个人合法用途，请遵守相关平台服务条款
